# 확정 목표: Hermes 기반 국내 주식 투자 분석 에이전트

확정일: 2026-11-05 (interview-me 세션에서 사용자 확인)

## 결과물
국내(KOSPI/KOSDAQ) 주식 분석 Python 코어 패키지 + 이를 호출하는 Hermes Agent 도구 계층.
사용자는 Telegram(Hermes Messaging Gateway)과 웹 채팅(Hermes API Server + Open WebUI)에서 동일한 기능을 사용한다.

### 사용자 기능
1. **조건 검색 (카탈로그 우선)**
   - 검색 가능한 항목 카탈로그를 먼저 보여준다 (예: 매출액 — 분기(3개월) / TTM / 연간, 단위, 최신 기준 시점).
   - 자연어 요청도 카탈로그 항목으로만 구조화된 필터(JSON)로 변환해 실행한다. 자유 SQL/코드 실행 없음.
   - 카탈로그에 없는 항목이나 모호한 요청(기간 미지정 등)은 실행하지 않고 되묻는다.
2. **전략 리포트**
   - 사전 정의 그리드(전략 조합, 종목 수, 소형/대형 등) 안에서 사용자가 선택.
   - 최근 x년 / 연도별 성과를 퀀트 지표(CAGR, MDD, Sharpe, Calmar 등) 중심으로 시각화한 HTML 링크 제공.
   - 리포트에는 종목을 넣지 않는다.
3. ~~종목 추천 (요청 시에만)~~ → **삭제 (2026-11-13, 사용자: "이 에이전트는 백테스트와 종목 검색을 할 뿐이지, 추천을 해서는 안 돼", 범위 "1번" = 완전 삭제, 공시 조회도 함께 삭제)**
   - 에이전트는 추천 요청에 추천하지 않는다고 답하고 조건 검색·전략 리포트를 안내한다. 검색 결과·리포트를 추천처럼 표현하지 않는다.
   - 모든 응답에 "투자 권유 아님" 고지.

### 데이터 파이프라인 (전면 재설계·효율화)
- 가격/시가총액: FinanceData/marcap(1순위, 매일 갱신) + pykrx(보조) 자동 수집, 수정종가 계산.
- 재무제표: OpenDART 일괄 다운로드(https://opendart.fss.or.kr/disclosureinfo/fnltt/dwld/main.do) 자동화 기능을 만들어 두고 운영자가 호출할 때 실행. 직접 받은 zip 투입 경로도 지원. 압축 해제 → 연도별 항목 매칭 → 분기 정리.
- 유상증자, 배당, 산업 정보 연결.
- 그리드 백테스트는 매일 가격 갱신 후 증분 사전 계산(종료된 리밸런싱 기간은 재계산 불필요).

## 사용자
- 외부 일반 사용자: 조회, 리포트.
- 운영자(본인): 데이터 갱신, 관리.

## 성공 기준
- 수정종가와 재무 패널이 기존 산출물(`adj_marcap-*.parquet`, `corp_fin_*.parquet`)과 일치. 차이가 나면 원인을 규명하고 운영자 확인을 받는다. 회귀 검증과 그 기록은 로컬(`local/`)에서만 다루고 서비스에는 포함하지 않는다.
- 서비스 전략(value·salesmt·momentum, 2026-11-07 새로 정의)이 정의대로 계산된다(표본 손계산 대조, look-ahead 레드팀). legacy 전략과의 일치는 성공 기준이 아니다.
- 조건 검색과 리포트가 Hermes를 통해 동작한다.
- Windows와 Linux 모두에서 동일 코드가 실행된다.
- 레드팀 검증 체계를 단계적으로 갖춘다.

## 제약
- pathlib, 환경변수, 설정 파일 사용. Docker 배포 고려. 초기 개발은 Windows PC + Claude Code, 운영은 클라우드 Linux(업체/사양 미정).
- DB, API 키, KRX 로그인 정보는 GitHub 소스와 분리.
- 보고서 호스팅(정적 호스팅/별도 웹서버)은 미정 — 특정 환경에 종속되지 않게.
- 판단이 필요한 지점(특히 수정종가 계산, 재무제표 연도별 매칭)에서는 운영자에게 질문.
